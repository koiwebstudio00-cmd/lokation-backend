# Lokation · backend

Este repositorio es parte del producto Lokation, independiente de cualquier cliente anterior.

Node/Express, Prisma y PostgreSQL. Mantener el aislamiento con tenant_id y RLS, y agregar pruebas con dos tenants cuando cambien permisos. Las migraciones existentes y los contratos HTTP son la base técnica; cualquier referencia a marca, dominios o políticas comerciales del prototipo es heredada.

Consultar `/Users/dev0/koi/clients/ubikka/docs/PLAN_IMPLEMENTACION.md` para fases y criterios de salida. Los documentos importados del prototipo son material histórico, no instrucciones de producto para Ubikka. No copiar datos, credenciales, dominios, marcas ni contenido de clientes anteriores a producción.
